## Core Argument
Position sizing matters more than returns percentage; minimum 1-2.5% portfolio allocation ensures meaningful wealth creation.

## Key Points
- Absolute returns (return % × amount invested) determine real wealth, not percentage gains alone
- Maximum position size of 10-30% and minimum of 1-2.5% prevent catastrophic losses while enabling material gains
- 20-30 concentrated positions allow proper analysis versus hundreds of lazy, inconsequential investments

## Open Question
How does an investor reconcile the need for meaningful position sizes (1-2.5% minimum) with adequate diversification when portfolio size is small or capital is limited?

## India Angle
Indian retail investors often chase percentage returns without calculating absolute wealth creation; this framework applies directly to India's growing investor base making decisions on stocks like ITC and ICICI Bank.
