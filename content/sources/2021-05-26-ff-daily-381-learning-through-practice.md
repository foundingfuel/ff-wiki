## Core Argument
Learning happens through supervised practice with graduated responsibility; hybrid work demands reimagining how organizations enable this.

## Key Points
- Novices learn best through hands-on practice under supervision, not passive instruction or observation.
- Hybrid work paradox: employees want flexibility AND in-person collaboration; requires rethinking synchronous/asynchronous knowledge transfer.
- Organizations must choose: value people's minds and agency, or expect obedience—this shapes culture and learning outcomes.

## Open Question
How can organizations enable experiential learning and mentorship—which requires presence and real-time feedback—in a hybrid, asynchronous-first work environment?

## India Angle
Indian organizations transitioning to hybrid work and gig models must grapple with how to build learning cultures that value employee agency and continuous practice—critical for knowledge-intensive sectors like IT, healthcare, and startups where residual informal apprenticeship models exist.
