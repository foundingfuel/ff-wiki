## Core Argument
State capacity depends on transaction volume, discretion required, stakes involved, and transparency—not just resources or intent.

## Key Points
- Lower transaction counts and fixed procedures increase likelihood of successful state implementation.
- High discretion and large private stakes (tax, justice, regulation) create corruption and influence risks.
- Public transparency and feedback loops strengthen state performance; secrecy masks poor execution.

## Open Question
How can the Indian state build capacity for high-discretion, high-stakes domains like criminal justice or financial regulation where the framework suggests it struggles most?

## India Angle
India's state capacity constraints directly limit which public interventions can succeed—immunization programs are feasible, but welfare systems requiring discretionary official judgment are not. This framework is critical for Indian policymakers designing development programs.
